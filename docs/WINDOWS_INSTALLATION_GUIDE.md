# Insight-Eye Windows 安装指南

## 系统要求

### 最低配置
- **操作系统**: Windows 10 64位 (版本 21H2 或更高)
- **内存**: 4GB RAM (推荐 8GB 以上)
- **硬盘空间**: 500MB 可用空间
- **显示器**: 1280x720 或更高分辨率

### 必需软件
- **ADB (Android Debug Bridge)**: 用于连接 Android 设备
  - 下载地址: https://developer.android.com/studio/releases/platform-tools
  - 或使用本工具提供的安装脚本: `install_amds.bat`

## 安装方法

### 方法 1: 便携版（推荐）

1. 下载 `Insight-Eye-Portable.zip`
2. 解压到任意目录（建议不要包含中文路径）
3. 双击 `启动应用.bat` 启动程序

**优点**:
- 无需安装，解压即用
- 卸载简单，直接删除目录即可
- 不写入系统注册表

### 方法 2: 安装版

1. 运行 `installer/install.bat`
2. 按照提示选择安装类型
3. 安装完成后，从开始菜单或桌面快捷方式启动

**优点**:
- 创建开始菜单和桌面快捷方式
- 方便启动和管理

## 首次使用配置

### 1. 安装 ADB

**方式一：手动安装**
1. 下载 Platform Tools
2. 解压到目录（如 `C:\platform-tools`）
3. 将目录添加到系统 PATH 环境变量

**方式二：使用自动安装脚本**
1. 右键点击 `install_amds.bat`
2. 选择"以管理员身份运行"
3. 脚本会自动下载并配置 ADB

### 2. 连接 Android 设备

1. **启用开发者选项**:
   - 设置 → 关于手机 → 连续点击"版本号" 7 次

2. **启用 USB 调试**:
   - 设置 → 开发者选项 → USB 调试（开启）

3. **连接设备**:
   - 使用 USB 线连接设备到电脑
   - 在设备上允许 USB 调试

4. **验证连接**:
   - 打开命令行，运行 `adb devices`
   - 应该显示设备序列号

### 3. 启动 Insight-Eye

双击 `启动应用.bat` 或快捷方式启动应用。

### 4. 选择设备和应用

1. 应用启动后会自动扫描设备
2. 在设备列表中选择您的 Android 设备
3. 在应用列表中选择要监控的应用
4. 点击"开始监控"按钮

## 功能使用

### 监控功能

- **CPU 使用率**: 实时显示应用和系统 CPU 占用
- **内存使用**: 监控应用内存消耗（Total/Native/Dalvik Heap）
- **帧率 (FPS)**: 实时显示应用帧率和卡顿情况
- **网络流量**: 监控上传/下载流量（KB/s）
- **电池状态**: 显示电量、温度、电流等信息

### 数据导出

支持导出格式：
- CSV: Excel 兼容格式
- JSON: 程序员友好格式
- Excel: 带格式化的表格
- Markdown: 报告文档

### 快捷键

- **F5**: 开始监控
- **F6**: 暂停/继续监控
- **Shift+F5**: 停止监控
- **F4**: 刷新设备列表
- **Ctrl+M**: 标记场景
- **Ctrl+E**: 导出数据

## 常见问题

### Q1: 无法识别设备
**解决方案**:
1. 检查 USB 数据线是否支持数据传输（不是仅充电线）
2. 确认设备已启用 USB 调试
3. 在设备上允许 USB 调试授权
4. 运行 `adb devices` 确认设备连接

### Q2: 应用崩溃或无响应
**解决方案**:
1. 检查 Windows 防火墙是否拦截
2. 确保没有其他实例在运行
3. 查看日志文件: `logs/app.log`

### Q3: 无法采集数据
**解决方案**:
1. 确认设备已正确连接
2. 检查应用是否在前台运行
3. 某些应用可能无法采集（如系统应用）

### Q4: 中文显示乱码
**解决方案**:
1. 确保系统编码为 UTF-8
2. 检查应用是否以管理员身份运行

### Q5: 卸载便携版
直接删除安装目录即可，不会留下系统残留。

### Q6: 卸载安装版
1. 通过"控制面板"→"程序和功能"卸载
2. 或手动删除安装目录和快捷方式

## 数据存储位置

- **数据库文件**: `data/insight_eye.db`
- **日志文件**: `logs/app.log`
- **导出数据**: 用户选择的导出目录
