本文档详细对比了桌面版和Web版报告面板的实现差异，列出了需要补齐的功能点。

### 核心组件功能

#### 1. Header区域 (report_panel.py:52-110)
- **标题**: "测试报告" (18pt, 粗体, #00d4ff)
- **筛选控件**:
  - 平台下拉框: "全部设备", "Android"
  - 搜索输入框: "搜索包名或应用名..."
  - 刷新按钮
  - 批量删除按钮 (#ef4444)

#### 2. 会话列表表格 (report_panel.py:123-167)
- **格式**: QTableWidget，2列
- **列标题**: "时间", "会话ID"
- **样式**:
  - 背景色: #121824
  - 选中: #00d4ff
  - 悬停: #1a1f2e
- **多选支持**: ExtendedSelection模式

#### 3. 紧凑会话信息栏 (session_report_widget.py:94-112)
- **样式**: 单行显示，背景 #0a0e17，底部边框 #1a1f2e
- **内容格式**: `设备: {设备名} | 应用: {包名} | 时间: {开始时间}-{结束时间} | 时长: {时长}`
- **字体**: 10pt, 颜色 #94a3b8

#### 4. 图表区域 (session_report_widget.py:69-75)
- **布局**: QGridLayout，2列×3行，最多6个图表
- **图表类型**: NeonChartCard (pyqtgraph)
- **优先级顺序**: cpu > fps > memory > network_down > network_up > gpu
- **最小高度**: 200px
- **间距**: 16px

#### 5. 统计面板 (stats_panel_widget.py)
- **最小宽度**: 280px
- **背景**: #0a0e17，左边框 #1a1f2e
- **可滚动**: QScrollArea
- **卡片样式**:
  - 背景: #121824
  - 圆角: 6px
  - 内边距: 8px
- **卡片内容**:
  - 标题: 9pt, #94a3b8
  - 平均值: 13pt, 粗体, #e0e6ed
  - 范围: 8pt, #64748b
- **网络特殊卡片**: 分上行/下行显示
- **告警区域**: 底部，最多20条，#ef4444标题

#### 6. 分隔器记忆 (session_report_widget.py:166-194)
- **保存位置**: `~/.config/insight_eye/report_layout.json`
- **默认比例**: 700:300 (70:30)
- **自动保存**: splitterMoved事件

#### 7. 底部操作按钮 (session_report_widget.py:114-164)
- **导出HTML**: #00d4ff边框，悬停反转
- **删除会话**: #ef4444边框，悬停反转
