## 概述

### 问题陈述

当前测试报告详情页面存在以下问题：
1. "会话信息"和"性能指标详情"占用过多垂直空间
2. 导出的报告（PDF/CSV）不包含重要图表
3. 缺少交互式数据查看能力

### 设计目标

- 优化UI布局，提升空间利用率 40%
- 实现交互式 HTML 报告导出
- 保持与应用一致的赛博朋克霓虹风格
- 支持离线查看和分享

---

## UI 布局优化设计

### 整体架构：分屏仪表盘

采用 **QSplitter** 实现左右分屏，支持拖动调整比例。

```
┌─────────────────────────────────────────────────────────────┐
│ 📊 性能测试报告                                        [刷新] │
├─────────────────────────────────────────────────────────────┤
│ 会话信息：📱 iPhone 13 Pro │ 📱 微信 │ ⏰ 30分钟           │
├───────────────────┬───────────────────────────────────────┤
│                   │ 📈 性能统计                            │
│   图表区域 (70%)  ├───────────────────────────────────────┤
│                   │ FPS    │ avg:42 max:60 min:28         │
│  ┌─────────────┐ │        │ 卡顿: 12 次                   │
│  │ FPS 趋势    │ ├───────────────────────────────────────┤
│  │             │ │ CPU    │ 35% (max:82% min:12%)        │
│  │  [图表]     │ ├───────────────────────────────────────┤
│  │             │ │ 内存   │ 320MB (max:520MB min:180MB)  │
│  └─────────────┘ ├───────────────────────────────────────┤
│                   │ ⚠️ 告警 (3)                           │
│  [更多图表...]   │ • 14:45 CPU > 80%                     │
│                   │ • 14:52 内存 > 500MB                 │
├───────────────────┴───────────────────────────────────────┤
│                      [导出HTML] [删除会话]                │
└─────────────────────────────────────────────────────────────┘
```

### 会话信息区域改造

**原布局**：多行垂直排列
- 设备名称
- 平台
- 应用包名
- 开始/结束时间
- 持续时间
- 采样间隔

**新布局**：单行紧凑横向
```
📱 {设备名} │ 📱 {应用名}({包名}) │ ⏰ {开始}-{结束} │ ⏱️ {时长}
```

### 图表区域（左侧 70%）

- 保持 2×3 网格布局
- 使用 `QScrollArea` 支持滚动
- 图表宽度自适应

### 统计面板（右侧 30%）

- **最小宽度**：左侧 500px，右侧 250px

- **状态持久化**：保存用户调整的分隔线位置

## HTML 交互式导出设计

### 技术选型

| 组件 | 技术 | 理由 |
|------|------|------|
| 图表库 | ECharts 5.4.3 | 功能强大、中文支持好、可离线 |
| 模板引擎 | Jinja2 | 灵活的 HTML 模板生成 |
| 样式 | 内联 CSS | 确保离线可用 |

### HTML 报告结构

```
report.html
├── <head>
│   ├── echarts.min.js (本地引用)
│   ├── cyberpunk_theme.js
│   └── 样式表 (赛博朋克主题)
├── <body>
│   ├── 头部：标题 + 会话摘要
│   ├── 关键指标卡片 (4个横向)
│   ├── 图表区域 (2×3网格)
│   │   ├── FPS 趋势图
│   │   ├── CPU 趋势图 (双曲线)
│   │   ├── 内存趋势图
│   │   ├── 网络上行/下行
│   │   └── 电池/温度 (如有)
│   ├── 统计数据表格
│   ├── 告警记录列表
│   └── 页脚
```

### ECharts 集成

#### 数据转换流程

```python
# 数据库 → Python 字典 → ECharts 配置 → JSON
database_data = repository.get_metrics_data(session_id)
chart_config = build_echarts_config(database_data)
json_config = json.dumps(chart_config)
```

#### Y 轴自适应策略

```javascript
function calculateYAxis(data, metricType) {
    const min = Math.min(...data);
    const max = Math.max(...data);
    const padding = (max - min) * 0.1;

    if (metricType === 'fps') {
        return { yMin: 0, yMax: max + padding };
        // 完全自适应，支持 200+ fps
    } else if (metricType === 'cpu') {
        return { yMin: 0, yMax: 100 };
    } else {
        return { yMin: 0, yMax: max + padding };
    }
}
```

#### 阈值线设计

- **类型**：虚线（表示参考值）
- **颜色**：半透明红色 (#ef4444, opacity: 0.6)
- **不限制 Y 轴**：仅作为视觉参考
- **可选**：显示设备刷新率参考线

### 交互功能

- **缩放**：鼠标滚轮缩放时间轴
- **提示**：悬停显示具体数值
- **图例**：点击显示/隐藏数据系列
- **数据视图**：双击打开数据表格

## 数据流与错误处理

### 导出流程

```
用户点击"导出HTML"
    ↓
验证会话数据
    ↓
获取数据 (session/metrics/statistics/alerts)
    ↓
数据转换 (时间格式化/单位转换/Y轴计算)
    ↓
生成 HTML (Jinja2 模板渲染)
    ↓
写入文件
    ↓
完成并显示路径
```

### 错误处理策略

| 错误场景 | 处理方式 |
|---------|---------|
| 数据获取失败 | 降级为简化报告（不含图表） |
| 数据为空 | 显示"无数据"提示，不中断导出 |
| ECharts 文件缺失 | 使用 CDN 链接，记录警告日志 |
| 文件写入失败 | 显示错误对话框，提示权限问题 |

### 性能优化

- **数据采样**：超过 1000 点时自动降频
- **内存缓存**：缓存 ECharts 库文件
- **渐进式渲染**：大数据时分批生成
