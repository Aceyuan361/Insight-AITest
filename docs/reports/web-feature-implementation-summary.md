## 🎯 功能1: 采样频率控制

### 实现内容

✅ **完整的数据流控制链路**:
```
前端UI → Store → API → 后端 → 数据采集循环
```

✅ **支持4种采样频率**:
- 1s (1000ms) - 默认
- 3s (3000ms)
- 5s (5000ms)
- 10s (10000ms)

✅ **动态调整**:
- 前端下拉框选择
- 实时同步到store
- 传递给后端API
- 应用到数据采集循环
