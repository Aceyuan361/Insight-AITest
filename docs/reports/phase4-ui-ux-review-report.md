### 桌面版 MonitorPanelV2

- **布局**: 2x2 网格
- **卡片组件**: `NeonChartCard`
- **图表**: `pyqtgraph` (折线图)
- **实时更新**: Qt Signals + QTimer

- **布局**: 2x2 网格

- **图表**: `ECharts` (折线图)

**对比结果**: ✅ 布局和交互逻辑一致
