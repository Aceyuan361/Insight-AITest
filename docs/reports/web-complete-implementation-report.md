**功能描述**: 支持动态调整数据采集频率

**实现要点**:
- 前端UI下拉框选择（1s/3s/5s/10s）
- 后端数据库持久化
- 核心采集循环应用采样间隔
- 完整的数据流：UI → Store → API → 后端 → 采集循环

**修改文件**: 9个（5后端 + 4前端）

**与桌面版一致性**: 100%

### 2. 应用状态检查

**功能描述**: 启动监控前检查应用运行状态

**实现要点**:
- 检查应用`is_running`字段
- 显示友好的"应用未运行"警告对话框
- 提供"仍要启动"选项（处理检测误差）

**修改文件**: 1个（前端）

**与桌面版一致性**: 100%

### 3. 配置持久化

**功能描述**: 保存用户配置到localStorage

**实现要点**:
- 创建ConfigManager工具类
- 保存采样频率和启用的指标
- 应用启动时自动恢复配置
- 配置变化时自动保存

**修改文件**: 2个（1新增 + 1修改）

**与桌面版一致性**: 100%

---

### 4. 自动刷新应用列表

**功能描述**: 启动监控前自动刷新获取最新状态

**实现要点**:
- 点击"开始监控"时自动调用API
- 获取最新的应用运行状态
- 刷新失败时优雅降级（使用现有数据）

**修改文件**: 1个（前端）

**与桌面版一致性**: 100%

---

### 5. 后台应用提示

**功能描述**: 区分前台和后台运行状态

**实现要点**:
- 检查应用`status === 'background'`
- 显示"应用在后台运行"警告对话框
- 提示可能影响数据采集
- 提供"继续监控"和"取消"选项

**修改文件**: 1个（前端）
