# 桌面版 vs Web版 UI 组件对比分析

**日期**: 2025-01-30
**目标**: 一比一复刻桌面版UI到Web版

---

## 一、桌面版UI结构（PyQt6）

### 整体架构

```
QMainWindow (主窗口)
├── MenuBar (菜单栏)
├── QSplitter (分割面板)
│   ├── DeviceSelectionPanel (左侧，设备选择)
│   └── MonitorPanelV2 (右侧，监控面板)
│       └── QGridLayout (2x2网格)
│           ├── [0,0] NeonChartCard (CPU)
│           ├── [0,1] NeonChartCard (Memory)
│           ├── [1,0] NeonChartCard (FPS)
│           └── [1,1] NeonChartCard (Network)
└── StatusBar (状态栏)
```

### 设计规范

| 元素 | 值 |
|------|-----|
| 主背景色 | `#0a0a0a` |
| 卡片背景 | `#141414` |
| 卡片最小高度 | 180px |
| 网格水平间距 | 15px |
| 网格垂直间距 | 12px |
| 卡片内边距 | 15px |

### 标题栏样式

```css
font-size: 1.2rem;
font-weight: 600;
color: #ffffff;
text-align: center;
letter-spacing: 2px;
text-transform: uppercase;
```

### NeonChartCard 组件

**结构**：
```
NeonChartCard (QFrame)
├── 标题栏 (标题 + 统计信息)
├── 当前值 (大号数值 + 单位)
└── 图表 (pyqtgraph PlotWidget)
```

**样式**：
- 顶部边框：2px solid {accent_color}
- 圆角：12px
- 霓虹色：根据指标类型
