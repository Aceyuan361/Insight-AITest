# Insight-Eye 测试报告功能使用指南

## 功能概述

测试报告系统为 Insight-Eye 提供了完整的监控数据回溯和分析功能。

## 快速开始

### 1. 启动应用

```bash
python -m insight_eyes
```

### 2. 开始监控

1. 选择设备和应用
2. 点击"开始监控"按钮
3. 进行性能测试

### 3. 查看报告

监控停止后，系统会：
1. 显示"处理监控数据"对话框
2. 自动处理数据（停止采集→保存数据→生成报告→分析异常）
3. 自动切换到"测试报告"视图
4. 高亮显示最新的监控会话

## 界面导航

### 主窗口导航栏

顶部有两个导航按钮：

- **实时监控**: 切换到设备选择和实时监控视图
- **测试报告**: 切换到测试报告列表和详情视图

### 测试报告视图

#### 左侧：会话列表

显示所有历史监控会话，包含以下列：
- **时间**: 监控开始时间
- **设备**: 设备名称
- **应用**: 应用包名
- **时长**: 监控持续时间
- **状态**: 完成/进行中

**筛选功能**：
- 平台筛选：全部设备 / Android / iOS
- 搜索框：按包名或应用名搜索
- 刷新按钮：重新加载会话列表

#### 右侧：报告详情

##### 1. 会话信息卡片

显示基本信息：
- 设备名称和平台
- 应用包名
- 开始时间
- 结束时间
- 持续时间
- 采样间隔

##### 2. 性能指标汇总

显示统计数据：
- **FPS**: 平均帧率、卡顿次数
- **CPU**: 平均CPU使用率、峰值CPU
- **内存**: 平均内存使用、峰值内存
- **网络**: 总上传流量、总下载流量

##### 3. 图表标签页

包含4个图表标签：

- **FPS**: 帧率趋势图
- **CPU**: CPU使用率趋势
- **内存**: 内存使用趋势
- **网络**: 网络流量趋势

图表特性：
- 霓虹风格曲线
- 实时数据点显示
- 鼠标悬停查看数值
- 自动缩放

## 处理对话框

监控停止时自动显示，包含：

- **进度条**: 显示处理进度（0-100%）
- **状态标签**: 显示当前处理步骤
  - 停止数据采集...
  - 保存监控数据...
  - 生成性能报告...
  - 分析异常指标...
  - 完成
- **关闭按钮**: 处理完成后启用

## 数据导出

报告详情区域包含"导出报告"按钮（功能预留）：

计划支持：
- PDF 格式报告

## 使用技巧

### 1. 对比分析

选择多个会话，对比不同场景下的性能表现：
- 不同网络环境（WiFi/4G/5G）
- 不同设备型号
- 不同应用版本

### 2. 问题定位

通过报告定位性能问题：
- 查看FPS趋势，识别卡顿时间点
- 分析CPU峰值，找到性能瓶颈
- 检查内存增长，发现内存泄漏
- 监控网络流量，优化数据传输

### 3. 性能优化

基于报告数据优化应用：
- 识别高CPU使用的函数
- 优化内存分配策略
- 减少不必要的网络请求
- 提升帧率稳定性

## 常见问题

### Q: 为什么会话列表为空？

A: 需要先进行监控，停止后会话才会保存到数据库。

### Q: 如何删除旧的会话记录？

A: 当前版本需要直接操作数据库。后续版本会添加删除功能。

### Q: 报告数据可以导出吗？

A: 导出功能正在开发中，敬请期待。

### Q: 支持多会话对比吗？

A: 当前版本不支持，计划在未来版本中添加。

## 技术细节

### 数据存储

- 数据库: SQLite
- 位置: `data/insight_eye.db`
- 表结构:
  - `monitoring_sessions`: 会话信息
  - `performance_metrics`: 性能指标
  - `alerts`: 异常告警

### 性能优化

- 数据分页加载（每次最多100条）
- 图表数据点限制（最多1000个点）
- 异步数据加载
- 缓存机制
