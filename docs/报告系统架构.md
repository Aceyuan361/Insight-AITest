## 数据库表结构

```
monitoring_sessions (监控会话)
┌─────────────────┬──────────────┬─────┐
│ 字段            │ 类型         │ 说明│
├─────────────────┼──────────────┼─────┤
│ id              │ INTEGER      │ PK  │
│ device_id       │ TEXT         │ 设备│
│ package_name    │ TEXT         │ 应用│
│ start_time      │ TIMESTAMP    │ 开始│
│ end_time        │ TIMESTAMP    │ 结束│
│ sample_interval │ INTEGER      │ 间隔│
│ tags            │ TEXT (JSON)  │ 标签│
└─────────────────┴──────────────┴─────┘

performance_metrics (性能指标)
┌─────────────────┬──────────────┬─────┐
│ 字段            │ 类型         │ 说明│
├─────────────────┼──────────────┼─────┤
│ id              │ INTEGER      │ PK  │
│ session_id      │ INTEGER      │ FK  │
│ timestamp       │ TIMESTAMP    │ 时间│
│ cpu_app         │ REAL         │ CPU │
│ memory_pss      │ REAL         │ 内存│
│ fps             │ REAL         │ 帧率│
│ fps_jank_count  │ INTEGER      │ 卡顿│
│ network_up_speed│ REAL         │ 上传│
│ network_down    │ REAL         │ 下载│
│ battery_level   │ REAL         │ 电量│
└─────────────────┴──────────────┴─────┘
```
