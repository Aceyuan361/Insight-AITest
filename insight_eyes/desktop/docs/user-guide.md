## 1. 快速开始

### 1.1 系统要求

**硬件要求**：
- CPU: 双核及以上
- 内存: 2GB 及以上（推荐 4GB）
- 硬盘: 500MB 可用空间
- USB 接口: 用于连接移动设备

**软件要求**：
- 操作系统: Windows 10/11, macOS 10.15+, Linux
- Python: 3.9 或更高版本
- ADB: Android SDK Platform Tools（Android 设备）
- iTunes: macOS 上连接 iOS 设备需要

### 1.2 五分钟上手

```
1. 安装 Insight-Eye（详见第 2 章）
   ↓
2. 连接 Android/iOS 设备到电脑
   ↓
3. 启动 Insight-Eye
   ↓
4. 点击"刷新"按钮扫描设备
   ↓
5. 选择要监控的应用
   ↓
6. 按 F5 开始监控
   ↓
7. 查看实时性能数据
```

## 2. 安装指南

### 2.1 Windows 安装

#### 步骤 1：安装 Python

1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.9 或更高版本
3. 运行安装程序，**务必勾选"Add Python to PATH"**
4. 验证安装：打开命令提示符，输入 `python --version`

#### 步骤 2：安装 ADB（Android 用户）

1. 下载 Android SDK Platform Tools
   - 访问 https://developer.android.com/studio/releases/platform-tools
   - 下载 Windows 版本
2. 解压到目录，如 `C:\platform-tools`
3. 添加到系统 PATH：
   - 右键"此电脑" → 属性 → 高级系统设置
   - 环境变量 → 系统变量 → Path → 编辑
   - 新建 → 输入 `C:\platform-tools`
4. 验证安装：打开命令提示符，输入 `adb version`

#### 步骤 3：安装 Insight-Eye

```bash
# 克隆项目
git clone https://github.com/Aceyuan361/Insight-Eye.git
cd Insight-Eye

# 安装依赖
pip install -r requirements.txt

# 启动应用
python -m insight_eyes.desktop.main
```

### 2.2 macOS 安装

#### 步骤 1：安装 Python

```bash
# 使用 Homebrew 安装
brew install python@3.9
```

#### 步骤 2：安装 ADB（Android 用户）

```bash
# 使用 Homebrew 安装
brew install android-platform-tools

# 验证安装
adb version
```

#### 步骤 3：安装 tidevice（iOS 用户）

```bash
pip install tidevice
```

#### 步骤 4：安装 Insight-Eye

```bash
# 同 Windows 安装步骤
```

### 2.3 Linux 安装

```bash
# 安装 Python（Ubuntu/Debian）
sudo apt update
sudo apt install python3.9 python3-pip

# 安装 ADB
sudo apt install android-tools-adb

# 安装 Insight-Eye
pip3 install -r requirements.txt
python3 -m insight_eyes.desktop.main
```

## 3. 设备连接

### 3.1 Android 设备连接

#### USB 连接

1. **开启 USB 调试**：
   - 设置 → 关于手机 → 连续点击"版本号" 7 次
   - 返回设置 → 开发者选项 → 打开"USB 调试"

2. **连接设备**：
   - 使用 USB 线连接手机和电脑
   - 手机弹出"允许 USB 调试"提示，点击"允许"

3. **验证连接**：
   ```bash
   adb devices
   # 应该显示你的设备
   List of devices attached
   XXXXXXXXXXXX	device
   ```

4. **在 Insight-Eye 中刷新**：
   - 点击左侧"刷新"按钮或按 F4
   - 设备会出现在左侧设备列表中

#### Wi-Fi 连接（Android 11+）

1. **先通过 USB 连接**（首次配对需要）
2. **启用无线调试**：
   ```bash
   adb tcpip 5555
   ```
3. **连接到设备 IP**：
   ```bash
   adb connect 192.168.1.100:5555  # 替换为实际 IP
   ```
4. **拔掉 USB 线**，设备保持连接

**获取设备 IP**：
- 设置 → 关于手机 → 状态信息 → IP 地址

### 3.2 iOS 设备连接

#### USB 连接

1. **信任电脑**：
   - 使用 USB 线连接 iPhone 和电脑
   - iPhone 弹出"信任此电脑"提示，点击"信任"

2. **验证连接**：
   ```bash
   tidevice list
   # 应该显示你的设备
   ```

3. **在 Insight-Eye 中刷新**：
   - 点击左侧"刷新"按钮
   - 设备会出现在列表中

#### 注意事项

- iOS 需要安装 iTunes（Windows）或信任电脑（macOS）
- 首次连接需要在 iPhone 上输入锁屏密码
- 某些企业设备可能无法连接（MDM 限制）

### 3.3 设备未识别？

#### Android

| 问题 | 解决方案 |
|------|----------|
| 设备显示为"unauthorized" | 在手机上重新授权 USB 调试 |
| 设备显示为"offline" | 重启 ADB: `adb kill-server && adb start-server` |
| 完全检测不到设备 | 更换 USB 线或 USB 端口 |

#### iOS

| 问题 | 解决方案 |
|------|----------|
| tidevice 找不到设备 | 确保 iTunes 已安装并信任电脑 |
| 连接不稳定 | 更换原装 USB 线 |
| 提示"请信任电脑" | 在 iPhone 上重新信任 |

## 4. 应用监控

### 4.1 选择应用

1. **在左侧设备列表中**：
   - 点击设备名称前的箭头展开应用列表
   - 勾选要监控的应用（自动开始监控）

2. **搜索功能**：
   - 在搜索框中输入应用名称或包名
   - 列表自动过滤匹配项

### 4.2 开始监控

#### 方法 1：快捷键（推荐）

- **F5**：开始监控
- **F6**：暂停/继续监控
- **Shift+F5**：停止监控

#### 方法 2：工具栏

点击工具栏上的"开始"按钮

#### 方法 3：菜单栏

工具 → 开始监控

### 4.4 场景标记

在测试过程中，可以标记关键场景以便后续分析：

1. **标记场景**：按 `Ctrl+M` 或点击工具栏"标记场景"
2. **输入场景名称**：如"启动App"、"滑动列表"、"加载图片"
3. **标记成功**：场景名称会显示在图表上

**常用场景**：
- 启动App
- 冷启动/热启动
- 列表滑动
- 视频播放
- 页面跳转
- 网络请求

### 4.5 停止监控

1. **按 Shift+F5** 或点击"停止"按钮
2. **自动弹出提示**：询问是否导出数据
3. **选择"是"**：保存数据并生成报告
4. **选择"否"**：放弃本次监控数据

## 5. 数据可视化

### 5.1 核心指标仪表盘

#### FPS（帧率）

- **显示内容**：当前帧率
- **正常范围**：50-60 FPS
- **警告阈值**：< 30 FPS
- **关联指标**：卡顿次数（Jank）

**什么是 FPS？**
- FPS = Frames Per Second（每秒帧数）
- 60 FPS = 每秒刷新 60 次，流畅
- 30 FPS = 每秒刷新 30 次，可接受
- < 30 FPS = 明显卡顿

#### CPU

- **显示内容**：应用 CPU 使用率
- **正常范围**：< 60%
- **警告阈值**：> 80%

**CPU 过高的原因**：
- 复杂计算
- 频繁 GC（垃圾回收）
- 死循环

#### 内存

- **显示内容**：PSS 内存（Proportional Set Size）
- **正常范围**：< 300 MB
- **警告阈值**：> 500 MB

**内存类型**：
- **PSS**：应用实际占用内存（含共享库按比例分配）
- **Native**：C/C++ 代码占用
- **Dalvik**：Java/Kotlin 代码占用

#### 网络

- **显示内容**：上行/下行速度
- **单位**：KB/s 或 MB/s

**网络异常**：
- 上行为 0 但下行 > 0：可能上传异常
- 长时间无数据：网络中断

### 5.2 趋势图表

#### FPS 趋势图

**用途**：分析帧率波动情况

**查看要点**：
- 波动频率：频繁波动说明性能不稳定
- 最低值：关注最低 FPS 时刻
- 卡顿点：红色点表示严重卡顿

#### 内存趋势图

**用途**：检测内存泄露

**内存泄露特征**：
- 持续上升，无回落
- 长时间监控后内存远超初始值

**正常内存模式**：
- 上升后回落（GC 回收）
- 在一定范围内波动

#### CPU 趋势图

**用途**：分析 CPU 使用模式

**常见模式**：
- **尖峰**：偶发高 CPU，可能是特定操作
- **持续高位**：长时间高 CPU，可能有性能问题
- **周期性**：定时任务导致

#### 网络趋势图

**双曲线**：
- 蓝色：上行（上传）
- 橙色：下行（下载）

**用途**：
- 分析网络请求模式
- 检测异常流量

### 5.3 图表交互

#### 缩放

- **鼠标滚轮**：放大/缩小
- **拖动**：平移图表

#### 查看数值

- **鼠标悬停**：显示精确数值和时间戳

#### 切换图表

- 点击标签页：[FPS] [内存] [CPU] [网络] [电池]

## 6. 配置管理

### 6.1 采集配置

**位置**：右侧配置面板 → 采集配置

#### 采样频率

| 选项 | 间隔 | 适用场景 |
|------|------|----------|
| 高频 | 100ms | 性能测试、精细分析 |
| 标准 | 1000ms | 日常监控（推荐） |
| 低频 | 5000ms | 长时间稳定性测试 |
| 极低频 | 10000ms | 24 小时监控 |

**注意事项**：
- 频率越高，数据量越大
- 高频采集可能影响设备性能
- 建议：日常使用标准频率

#### 监控指标开关

勾选/取消勾选以启用/禁用指标：

- ☑ CPU
- ☑ 内存
- ☑ FPS
- ☑ 网络
- ☑ 电池
- ☐ GPU（未实现）

### 6.2 阈值设置

**位置**：右侧配置面板 → 告警阈值

#### FPS 阈值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 警告 FPS | 30 | 低于此值显示黄色警告 |
| 严重 FPS | 20 | 低于此值显示红色告警 |
| 大卡顿帧时间 | 100ms | 单帧超过此时间视为大卡顿 |

**设置建议**：
- 游戏、视频应用：设置更高（警告 50，严重 40）
- 普通应用：使用默认值

#### 内存阈值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 高内存告警 | 500 MB | 超过此值触发告警 |
| 泄露检测增长 | 100 MB | 5 分钟内增长超过此值 |

**设置建议**：
- 轻量应用：300 MB
- 中型应用：500 MB
- 大型应用：800 MB

#### CPU 阈值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 高 CPU 告警 | 80% | 超过此值触发告警 |
| 持续高 CPU | 60% | 超过 1 分钟视为异常 |

### 6.3 保存配置模板

1. **调整配置**到满意状态
2. **菜单栏**：文件 → 保存模板
3. **输入模板名称**：如"性能测试标准配置"
4. **保存**

**加载模板**：
- 文件 → 加载模板 → 选择模板

### 6.4 重置配置

**重置为默认**：
- 配置 → 重置配置 → 确认

## 7. 数据导出

### 7.1 导出格式对比

| 格式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| CSV | 体积小，兼容性好 | 不支持多表 | 简单数据分析 |
| JSON | 结构化，支持嵌套 | 文件较大 | 程序间数据交换 |
| Excel | 多工作表，可读性强 | 需要安装 openpyxl | 人工查看分析 |
| Markdown | 报告格式清晰 | 不适合数据导入 | 测试报告生成 |

### 7.2 导出步骤

1. **停止监控**（Shift+F5）
2. **选择"是"导出数据** 或 菜单栏 → 文件 → 导出数据
3. **选择格式**：CSV/JSON/Excel
4. **选择保存位置**
5. **等待完成**

### 7.3 生成测试报告

1. **停止监控**
2. **菜单栏**：文件 → 生成报告
3. **选择输出目录**
4. **自动生成 Markdown 报告**

**报告内容**：
- 监控概览（时长、设备、应用）
- 核心指标统计（平均值、最大值、最小值）
- 异常告警汇总
- 性能趋势分析
- 优化建议

### 7.4 批量导出

**导出多个会话**：
1. 菜单栏 → 工具 → 数据管理
2. 选择多个会话
3. 点击"批量导出"
4. 选择格式和输出目录

## 8. 常见问题

### 8.1 安装问题

#### Q: 提示"找不到 Python"

**A**:
1. 确认 Python 已安装：`python --version`
2. 如果未安装，参考[第 2 章](#2-安装指南)
3. 如果已安装，添加 Python 到 PATH

#### Q: pip 安装依赖失败

**A**:
```bash
# 使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 或升级 pip
pip install --upgrade pip
```

#### Q: 启动时报错"No module named 'PyQt6'"

**A**:
```bash
pip install PyQt6
```

### 8.2 设备连接问题

#### Q: 设备显示"unauthorized"

**A**:
1. 在手机上重新授权 USB 调试
2. 重启 ADB：`adb kill-server && adb start-server`
3. 重新插拔 USB 线

#### Q: iOS 设备连接不稳定

**A**:
1. 使用原装 USB 线
2. 在 iPhone 上重新信任电脑
3. 重启 tidevice：`tidevice list`

#### Q: Wi-Fi 连接后设备离线

**A**:
1. 确保手机和电脑在同一局域网
2. 检查手机 IP 是否变化
3. 重新连接：`adb connect <IP>:5555`

### 8.3 监控问题

#### Q: 监控无数据

**A**:
1. **确认应用正在运行**：在手机上打开应用
2. **检查采集配置**：确认指标开关已打开
3. **查看日志**：`~/.insight_eye/logs/app.log`
4. **重启应用**：关闭并重新启动 Insight-Eye

#### Q: FPS 显示为 0

**A**:
1. **Android**：确认应用有 Activity 界面（服务类应用无 FPS）
2. **iOS**：tidevice 对 FPS 支持有限
3. **重试**：停止监控后重新开始

#### Q: 内存数据不准确

**A**:
1. **理解内存类型**：PSS 包含共享库，可能高于预期
2. **查看详细内存**：导出数据查看 Native/Dalvik 分量
3. **等待 GC**：Android 可能延迟回收内存

### 8.4 性能问题

#### Q: 应用卡顿

**A**:
1. **降低采样频率**：改为标准或低频
2. **关闭不需要的指标**：取消 GPU 等未实现指标
3. **减少监控设备数量**：同时监控多设备可能卡顿
4. **导出旧数据**：清理数据库

#### Q: 数据库文件过大

**A**:
1. **清理旧数据**：工具 → 清理数据 → 选择保留天数
2. **手动删除**：删除 `~/.insight_eye/data/insight_eye.db`
3. **定期备份**：工具 → 备份数据

### 8.5 导出问题

#### Q: Excel 导出失败

**A**:
```bash
pip install openpyxl
```

#### Q: 导出的 CSV 文件乱码

**A**:
使用 UTF-8 编码打开 CSV 文件，或使用 Excel 导入（选择 UTF-8）

### 8.6 其他问题

#### Q: 如何查看日志？

**A**:
日志位置：`~/.insight_eye/logs/app.log`

Windows: `C:\Users\<用户名>\.insight_eye\logs\app.log`
macOS: `~/.insight_eye/logs/app.log`

#### Q: 如何卸载？

**A**:
1. 删除项目目录
2. 删除配置目录：`~/.insight_eye`
3. 卸载 Python 依赖（可选）

#### Q: 如何获取技术支持？

**A**:
- GitHub Issues: https://github.com/Aceyuan361/Insight-Eye/issues
