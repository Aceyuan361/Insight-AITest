# 监控面板优化功能指南

## 📋 功能概述

本次更新大幅优化了监控面板的显示效果和用户体验，新增了测试报告功能：

### 1. 曲线显示优化
- **抗锯齿渲染**: 曲线边缘更平滑，无锯齿感
- **样条插值**: 数据点之间自动平滑过渡
- **数据点数量**: 从 60 增加到 120 个，获得更细腻的曲线
- **性能优化**: 启用硬件加速，减少渲染开销

### 2. 数据悬停提示
- 鼠标悬停在曲线上时显示垂直参考线
- 高亮显示最近的数据点（带发光效果）
- 浮动提示框显示精确的时间和数值
- 提示框跟随鼠标移动，智能调整位置

### 3. 动态监控卡片
- 支持启用/禁用各类监控指标
- 自适应网格布局：
  - 1-2 个指标：1-2 列布局
  - 3-4 个指标：2x2 布局（默认）
  - 5-6 个指标：2x3 布局
  - 更多指标：3 列或 4 列布局
- 新增 Battery 和 GPU 指标支持（默认禁用）

### 4. 测试报告面板
- 查看历史监控会话列表
- 详细查看每次监控的数据
- 重现性能走势图
- 查看完整的指标数据表格
- 导出测试报告（CSV/JSON/Excel）

### 5. 配置管理增强
- 新增 `card_configs.py` 模块，统一管理所有卡片配置
- `CollectionConfig` 支持指标开关配置
- 配置面板新增指标选择器
- 配置变更实时生效，无需重启应用

## 🚀 使用方法

### 配置监控指标

1. 打开应用，点击右上角"配置"按钮
2. 在"监控指标"区域勾选/取消指标
3. 点击"应用"按钮保存配置
4. 监控面板自动更新布局

**提示**：
- 默认启用：CPU、内存、FPS、网络
- 可选指标：电池温度、GPU 使用率
- 指标按优先级自动排序，保持良好的视觉布局

### 查看悬停数据

1. 启动性能监控
2. 将鼠标移动到曲线图上
3. 查看浮动提示框中的数据：
   - 时间戳（精确到秒）
   - 当前数值（带单位）
   - 指标名称

**提示**：
- 提示框会自动调整位置，避免遮挡数据
- 按 ESC 键可以快速隐藏提示框
- 垂直参考线帮助对齐时间点

### 查看测试报告

1. 停止监控后，点击左侧"测试报告"按钮
2. 在左侧列表选择要查看的会话
3. 右侧显示详细的性能数据：
   - **概览卡片**: 显示会话时长、设备信息、应用名称
   - **图表**: 4 个子图显示 CPU、内存、FPS、网络趋势
   - **数据表格**: 所有采样点的详细数据

**提示**：
- 双击会话可以快速查看详情
- 支持滚动缩放图表
- 数据表格支持排序和筛选

### 数据管理

#### 清除数据
- 点击"清除数据"按钮清除当前图表
- 清除操作不会影响已保存的历史记录

#### 导出数据
- 点击"导出"按钮选择导出格式
- 支持格式：CSV、JSON、Excel (XLSX)、Markdown
- 导出位置：`export/` 目录

## 🔧 技术细节

### 数据点上限

- **历史版本**: 60 个数据点
- **当前版本**: 120 个数据点
- **采样频率**: 默认 1 秒
- **监控时长**: 最多 2 分钟的实时数据

### 性能优化

- **抗锯齿**: 使用 PyQt6 的 `setAntialiasing(True)`
- **硬件加速**: 启用 `WA_OpaquePaintEvent` 和 `WA_NoSystemBackground`
- **渲染优化**: 限制图表更新频率 ≤30fps
- **内存管理**: 使用有界队列，防止内存泄漏

### 线程安全

- 所有数据更新都在主线程执行
- 使用 Qt 信号/槽机制进行跨线程通信
- 卡片清理时正确断开信号连接，防止内存泄漏

## 🐛 已知问题与解决

### 问题 1: 悬停提示不显示

**原因**: tooltip_widget 模块未正确导入

**解决**:
```python
# 确保已创建 tooltip_widget.py
from insight_eyes.desktop.ui.widgets.tooltip_widget import ChartTooltip
```

### 问题 2: 图表卡顿

**原因**: 数据点过多或采样频率过高

**解决**:
- 降低采样频率（修改 `collection.interval_ms`）
- 减少数据点上限（修改 `NeonChartCard` 中的限制）
- 关闭抗锯齿（性能优先时）

### 问题 3: 配置未生效

**原因**: 配置文件权限或路径问题

**解决**:
1. 检查配置文件路径：`~/.insight_eyes/config.json`
2. 确保有写入权限
3. 尝试删除配置文件，让应用重新生成

## 🎯 最佳实践

### 1. 监控场景配置

**应用启动性能测试**:
- 启用指标：CPU、内存、FPS
- 采样频率：500ms
- 监控时长：30 秒

**长时间稳定性测试**:
- 启用指标：全部
- 采样频率：1000ms
- 监控时长：>10 分钟

**网络性能测试**:
- 启用指标：网络、FPS
- 采样频率：200ms
- 监控时长：2 分钟

### 2. 数据分析技巧

- **趋势分析**: 观察曲线的整体走向，识别性能趋势
- **峰值分析**: 使用悬停功能查看峰值点的精确数值
- **对比分析**: 导出多次测试的数据，使用 Excel 进行对比
- **异常检测**: 关注突变的点，可能表示性能问题

### 3. 性能优化建议

- 减少启用的指标数量（只保留必要的）
- 适当增加采样间隔（降低 CPU 占用）
- 定期清理历史记录（避免数据库过大）
- 在高性能机器上运行（确保渲染流畅）
